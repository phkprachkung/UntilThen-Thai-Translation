## 🛠️ อัปเดตล่าสุด - อัปเดตแก้บัค DLC ล่าสุด
* **อัปเดตระบบให้รองรับ DLC ล่าสุด:** ทำการแก้ปัญหาเกมค้างและเด้ง เวลาเปิดดูหน้าโปรไฟล์เพื่อนในแชท ที่เกิดจากโครงสร้าง UI แบบเก่าชนกับอัปเดตใหม่ ตอนนี้กดดูโปรไฟล์และแชทได้ลื่นไหล 100% ไม่มีเด้งแล้ว!
* **คลีนอัปไฟล์ขยะในโปรเจกต์มอด:** ลบไฟล์ของตัวเกมหลักที่ไม่ได้มีการดัดแปลงออกจากโฟลเดอร์มอดทั้งหมด เพื่อลดขนาดไฟล์มอดให้เล็กลง และป้องกันปัญหาบัคเวลาเกมมีการอัปเดตแพทช์ในอนาคต
* **แก้บัคตัวแปรข้อความ (String Formatting):** แก้ไขบัคโค้ด %s ที่หายไปในบรรทัดคำแปล CHAT_IS_TYPING ซึ่งเป็นสาเหตุแฝงที่อาจทำให้เกมแครชหรือเด้งเวลาตัวละครกำลังพิมพ์ข้อความแชท
* **อัปเดตโครงสร้างสคริปต์โซเชียล/แชท:** ถอดสคริปต์แชทภาษาไทยตัวเก่าที่ล้าสมัยออก และดึงสคริปต์ภาษาอังกฤษเวอร์ชันอัปเดตล่าสุดจาก DLC กลับเข้ามาแทนที่ เพื่อป้องกันบัคเนื้อเรื่องและเตรียมพร้อมสำหรับการแปลต่อในลูปใหม่ (rdvt)


## 📝 อัปเดตล่าสุด (v1.4.1)
* **แก้บั๊กสเปซบาร์เจ้าปัญหา:** ค้นพบสาเหตุที่แท้จริงของบั๊กจอดำ/เด้งหลุดตอนเล่นเปียโน ซึ่งเกิดจากการเผลอพิมพ์อักษร Non-Breaking Space (NBSP) เข้าไปในไฟล์แปล ทำให้เกมอ่านโค้ดไม่ออก 
* **กลับมาเป็นภาษาไทย 100%:** ทำการแก้บั๊ก NBSP ในไฟล์ `.inkb` เรียบร้อยแล้ว ตอนนี้ฉากรอยต่อทั้งหมด (รวมถึงฉากคุยตอนกลางคืน) **กลับมาเป็นภาษาไทย 100%** แบบไม่มีเด้งแล้วครับ!
* **แก้บั๊กเกมค้าง (Not Responding)** ในฉากเดินในห้องชมรม (ลูป 1 บทที่ 3) ตอนนี้สามารถกดคุยกับเพื่อนได้ปกติโดยใช้ไฟล์ภาษาไทยเต็มรูปแบบแล้วครับ
* **อัปเดตระบบติดตั้งม็อด:** เพิ่มตัวติดตั้ง `.NET 9.0 Desktop Runtime` แบบออฟไลน์มาในตัว 

---
* **เนื้อเรื่องทั้งหมด (Story):** 💯 97% (แปลเนื้อเรื่องหลักครบจบเกมแล้ว!)
* **เมนูและอินเตอร์เฟส (UI):** ✅ 90% (แปลข้อความส่วนที่ลึกที่สุดของโค้ด เช่น แอปพยากรณ์อากาศ, หน้าจอซื้อตั๋วรถไฟ, คำสั่งโซเชียลมีเดีย)

## ⚙️ วิธีการติดตั้งม็อดภาษาไทย (อัปเดตใหม่ ง่ายขึ้นกว่าเดิม!)

เพื่อความสะดวกและรวดเร็ว เราได้สร้างโปรแกรมติดตั้งม็อดแบบอัตโนมัติ (Installer) ให้คุณแล้ว!

**ขั้นตอนการติดตั้ง:**
1. ดาวน์โหลดไฟล์ **`UntilThen_ThaiMod_Setup.exe`** จากหน้า [Releases](https://github.com/phkprachkung/UntilThen-Thai-Translation/releases)
2. ดับเบิ้ลคลิกเพื่อรันโปรแกรมติดตั้ง และทำตามขั้นตอนบนหน้าจอ
3. เมื่อเปิดโปรแกรมติดตั้งม็อด โปรแกรมจะค้นหาโฟลเดอร์เกมใน Steam ให้โดยอัตโนมัติ (หรือกดปุ่ม BROWSE เพื่อเลือกหาไฟล์เกมเองในกรณีที่ใช้แพลตฟอร์มอื่น)
4. กดปุ่ม **INSTALL MOD** และรอสักครู่จนกว่าระบบจะดำเนินการเสร็จสิ้น
5. เสร็จเรียบร้อย! สามารถเข้าเกมและสนุกกับเนื้อเรื่องภาษาไทยได้ทันทีครับ

*(หากต้องการถอนการติดตั้งม็อดและคืนค่าเป็นเกมดั้งเดิม สามารถเปิดโปรแกรมนี้และกดปุ่ม **UNINSTALL MOD** หรือจะใช้ระบบถอนการติดตั้งโปรแกรมผ่าน Control Panel ใน Windows ตามปกติก็ได้เช่นกันครับ)*

<details>
<summary><b>คลิกที่นี่ หากต้องการติดตั้งแบบ Manual (วิธีเก่าโดยใช้โปรแกรมแพ็คไฟล์ด้วยตัวเอง)</b></summary>

ในโฟลเดอร์นี้คือไฟล์ Source ของม็อดแปลภาษาไทย ที่คุณสามารถนำไปแพ็คอัปเดตไฟล์ `.pck` ดั้งเดิมของตัวเกมได้เลย

**สิ่งที่ต้องเตรียม:**
1. โปรแกรม **Godot PCK Explorer**
2. ไฟล์ Source Code โฟลเดอร์ `game` จาก Repository นี้

**ขั้นตอนการติดตั้งและแพ็คไฟล์:**
1. เปิดโปรแกรม **Godot PCK Explorer** ไปที่เมนู `File > Open File` เลือกไฟล์ `UntilThen.pck` ของตัวเกมในโฟลเดอร์ Steam
2. เลือกเมนู `Extract > Extract All` เพื่อแตกไฟล์ทั้งหมดของเกมออกมา (แนะนำให้สร้างโฟลเดอร์ `game` รอไว้แล้วแตกไฟล์ลงไป)
3. นำโฟลเดอร์ `game` จาก Source Code ของเรา **ไปลากวางทับ** โฟลเดอร์เกมที่คุณเพิ่งแตกไฟล์มา (กดยอมรับ Replace All)
4. ในโปรแกรม Godot PCK Explorer ไปที่เมนู `File > Pack or Embed Folder`
5. ตั้งค่าการแพ็กไฟล์ดังนี้:
   - **Path to the folder to pack:** เลือกโฟลเดอร์ `game` ที่เพิ่งวางม็อดทับไป
   - ติ๊กถูกที่ **Enabled patching** แล้วเลือกไฟล์ `UntilThen.pck` ต้นฉบับ
   - กำหนดเวอร์ชันเป็น **Godot 4.1.4**
6. กด **Pack** ระบบจะถามหาที่เซฟ ให้ตั้งชื่อเป็น `UntilThen.pck` แล้วบันทึกทับไฟล์เกมตัวเก่าใน Steam ไปเลย 
*(⚠️ แนะนำให้สำรองไฟล์ `.pck` ต้นฉบับของเกมเก็บไว้ก่อน)*
7. คุณสามารถลบโฟลเดอร์ที่แตกออกมาทิ้งไปได้เลย เข้าเกมและสนุกกับเนื้อเรื่องภาษาไทยได้ทันที!
</details>
